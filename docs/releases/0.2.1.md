BEAT Engine 0.2.1 fixes the version reported by the 0.2.0 package.

- `beat_engine.__version__` and the worker contract's engine version now read
  `0.2.1`. The 0.2.0 wheel still reported `0.1.0` there, while its package
  metadata said `0.2.0`.
- Adds a test that keeps `pyproject.toml` and `__version__` in step.

No solver, protocol, or result-schema changes since 0.2.0.

Install the wheel into the application's Python environment, then prepare
the relevant Julia project with `python -m beat_engine instantiate --backend
metal` (or `cpu`/`cuda`/`rocm`). Boundary Lab must update its exact
package-version check and wheel URL/SHA-256 together, and existing
application workers must be restarted after an upgrade.
